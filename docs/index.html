MobGrind

AFK XP-farming for any Minecraft mob spawner. It attacks on a jittered timer, rotates through your swords so they wear evenly, eats only when you're hungry, and stops itself if you die.

🍎 Download for macOS.dmg · drag to Applications 🪟 Download for Windows.exe · 64-bit

Latest release · free & open source · view on GitHub

What it does

🗡️

Sword rotation

Scrolls one hotbar slot after every swing, so all 9 swords share the durability instead of grinding one to dust.

🍗

Eats when hungry

Reads your hunger bar and only eats off-hand food when it actually drops — not on a blind timer.

💀

Stops on death

Watches for the death screen and shuts down, so a bad session doesn't swing at nothing for hours.

🎲

Human-ish timing

Every attack interval wobbles a little, so it's less robotic and less likely to desync.

🧭

Lives in your tray

A menu-bar / system-tray icon with Start, Pause, Calibrate and Quit. No terminal needed.

🖥️

Mac & Windows

One download per platform. Nothing to install — no Python, no setup.

Getting started

macOS

Open the .dmg and drag MobGrind into Applications. If it's an unsigned build, clear Gatekeeper once:

xattr -dr com.apple.quarantine /Applications/MobGrind.app

…or double-click, then System Settings → Privacy & Security → “Open Anyway”. On first Start or Calibrate, macOS asks for Accessibility and Screen Recording — grant both and relaunch.

Windows

Run the .exe. SmartScreen may warn on the unsigned build — click More info → Run anyway. No extra permissions needed.

Then open the tray icon and hit Calibrate once — hover your leftmost hunger haunch, then the screen center. That teaches it your HUD so the eat-when-hungry and death detection work. Start the macro, tab into Minecraft, and go AFK.

Play fair. Most multiplayer servers ban auto-clickers and AFK macros — using this on them can get you banned. Keep it to your own worlds, single-player, or servers that explicitly allow it.
